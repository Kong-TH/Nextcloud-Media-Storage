## Reference commands

Copy recursively clones metadata with fresh IDs in one transaction, revalidating original bindings against current accessible storage and bounding traversal to 1000 nodes and 128 levels. Root/bucket copy is forbidden. Duplicate names and unavailable bindings fail atomically. Copy into the source subtree is rejected. No credential/bearer endpoint is added. Multiple selected commands execute per root sequentially; report failures and refresh committed state, without implying batch atomicity. Clipboard stays in memory only.
