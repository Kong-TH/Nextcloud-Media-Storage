# Sprint Planning

Use sequential phase gates. Sprint duration and owners are not assigned.

Sprint 01 implements Phase 1 after the installed Nextcloud release is confirmed. Sprint 02 covers scoped API authentication; Sprint 03 the explorer; Sprint 04 delivery and protection; Sprint 05 release validation.

Before each sprint, select stories and acceptance checks. During implementation, keep architecture/API/schema documentation synchronized. At completion, record commands, environment, outcomes, and remaining gaps in the sprint and changelog. Never mark a test verified when execution is deferred.
