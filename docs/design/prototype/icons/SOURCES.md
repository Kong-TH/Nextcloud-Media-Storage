# Material Symbols assets

Google Material Symbols Outlined, optical size 24, from [google/material-design-icons](https://github.com/google/material-design-icons/tree/49d4db35df873165d6bd6ba09b063c7dafbac2f4). Downloaded 2026-10-09; Apache-2.0 license retained in LICENSE.

Original SVG files are stored unchanged. Inline SVG copies use currentColor in the prototype. No remote requests are made by the page.

Source pattern: `symbols/web/NAME/materialsymbolsoutlined/NAME_24px.svg`.

Included names: add, arrow_forward, close, menu, search, expand_more, folder, description, image, movie, info, grid_view, key, folder_open.

Additional reference-action icons: content_copy, content_paste, drive_file_move, delete, edit, more_horiz. Same source revision and license.
