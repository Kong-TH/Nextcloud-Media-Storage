# Nextcloud Media Storage

A planned native Nextcloud app (`mediastorage`) for virtual media organization using Nextcloud's existing filesystem, database, and authentication.

**Status:** Documentation baseline established. Application implementation has not started. Not installable or production ready.

Start with the [documentation index](docs/index.md), [project overview](docs/project-overview.md), and [Sprint 01](docs/agile/sprint-backlogs/sprint-01.md).

The installed Nextcloud version must be identified before selecting PHP, Vue, dependency versions, or an app compatibility range. No Nextcloud or database versions are currently verified.
